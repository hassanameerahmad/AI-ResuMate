# 📄 Resume ATS Analyzer

An AI-powered web app that analyzes resumes and provides an **estimated ATS score** with practical improvement suggestions.

## ✨ Features

- 📄 Upload **PDF, DOCX, or TXT** resumes
- 🤖 AI analysis using **Google Gemini Flash**
- 📊 Estimated **ATS score out of 100**
- 🎯 Job description & keyword matching
- 🚨 Identify critical resume issues
- 💪 Find resume strengths
- ✍️ Get improvement suggestions
- 📥 Download analysis as JSON

## 🛠️ Tech Stack

- **Python**
- **Streamlit**
- **Google Gemini Flash**
- **PyPDF**
- **python-docx**

## 🚀 Run Locally

### Install Dependencies

```bash
pip install -r requirements.txt
Add Your Gemini API Key

Add your Gemini API key to Streamlit Secrets:

GEMINI_API_KEY = "YOUR_API_KEY"
Run the App
streamlit run app.py
